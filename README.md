# C Language Programs — Maneet Tripathi

A collection of C programming exercises, practice problems, and core implementations written while building fundamentals in C and data structures.

## Overview

This repository tracks progress across fundamental and intermediate C concepts, including:

- Input/output, data types, and operators
- Conditional statements (`if`, `else if`, `switch`)
- Loops (`for`, `while`, `do-while`) and pattern/number logic
- Functions, recursion, and modular problem solving
- Arrays, strings, pointers, structures, and file handling
